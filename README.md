# Movie Library

**Автор:** Иван Иванов

## Описание

Это графическое приложение для хранения информации о фильмах. Пользователь может добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Также реализована фильтрация по жанру и году выпуска. Все данные сохраняются в файл `movies.json`.

## Использование

1. Введите название, жанр, год выпуска и рейтинг в соответствующие поля.
2. Нажмите кнопку «Добавить фильм» для добавления в список.
3. Используйте выпадающие меню для фильтрации по жанру и году.
4. В таблице отображаются фильмы, соответствующие текущим фильтрам.

## Примеры тестов

- Добавить фильм «Интерстеллар», жанр «Фантастика», год 2014, рейтинг 9.2.
- Установить фильтр по жанру «Фантастика» и убедиться, что отображаются только такие фильмы.
- Ввести некорректный год или рейтинг — должно появиться предупреждение.
